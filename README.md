# PomoTrack

Backend API для трекера задач с Pomodoro-сессиями. Пользователи регистрируются, создают категории и задачи, фиксируют рабочие сессии и перерывы и смотрят свою статистику. Каждый пользователь видит только свои данные.

## Стек

Python 3.12, FastAPI, SQLModel, PostgreSQL, Alembic, JWT (PyJWT, pwdlib/argon2),
pytest, Docker Compose, uv.

## Возможности

- Регистрация и вход с JWT
- Задачи и категории: CRUD, фильтрация, поиск, сортировка, пагинация
- Pomodoro-сессии (работа, короткий перерыв, длинный перерыв) с валидацией времени
- Статистика: сводка за период и время по категориям
- Изоляция данных между пользователями
- Индивидуальные настройки таймера (длительность работы и перерывов)
- Автоматические тесты и CI

## Быстрый старт (Docker)

    cp .env.example .env
    docker compose up --build

API доступен по адресу http://localhost:8000, интерактивная документация — http://localhost:8000/docs. Миграции базы данных применяются автоматически при запуске контейнера api.

## Локальный запуск (без Docker для API)

    cp .env.example .env
    docker compose up -d db
    uv sync
    uv run alembic upgrade head
    uv run uvicorn app.main:app --reload

## Запуск тестов

    uv run pytest

Тесты используют базу SQLite в памяти, поэтому никогда не затрагивают ваши реальные данные.

## Эндпоинты

| Группа | Метод | Путь | Описание |
|---|---|---|---|
| Auth | POST | /auth/register | Создать аккаунт |
| Auth | POST | /auth/token | Войти, получить JWT |
| Users | GET | /users/me | Текущий пользователь |
| Users | GET, PATCH | /users/me/settings | Настройки таймера |
| Categories | GET, POST | /categories/ | Список / создание |
| Categories | GET | /categories/{id}/tasks | Задачи категории |
| Categories | DELETE | /categories/{id} | Удаление (409, если есть задачи) |
| Tasks | GET, POST | /tasks/ | Список с фильтрами / создание |
| Tasks | GET, PUT, PATCH, DELETE | /tasks/{id} | Одна задача |
| Tasks | GET | /tasks/{id}/sessions | Сессии задачи |
| Sessions | GET, POST | /sessions/ | Список с фильтрами / создание |
| Sessions | DELETE | /sessions/{id} | Удалить сессию |
| Stats | GET | /stats/summary | Итоги за период |
| Stats | GET | /stats/by-category | Минуты по категориям |

## Проектные решения

- user_id берётся из токена, а не из тела запроса.
- Всё время хранится и сравнивается в UTC.
- Названия категорий уникальны для каждого пользователя.
- Категорию с задачами удалить нельзя (409).
- Сессии при удалении задачи удаляются каскадно.
- Миграции запускаются при старте контейнера, поэтому новому пользователю достаточно двух команд.
- Одинаковый текст ошибки при неверном логине и неверном пароле, плюс проверка «фиктивного» хеша, чтобы злоумышленник не мог узнать, какие имена пользователей существуют.
